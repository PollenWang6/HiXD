一、服务说明

本应用是一款面向西电师生的校园服务聚合工具，整合课表、成绩与考试、图书馆借阅与续借、座位预约、体测成绩、校园网等校内常用功能。本应用并非学校官方产品，相关数据的权威来源为学校各官方业务系统。

二、账号与登录

您需使用西电统一身份认证账号或校园网账号登录。您应妥善保管账号凭据，因账号泄露导致的后果由您自行承担。本应用不会存储您的明文密码。
